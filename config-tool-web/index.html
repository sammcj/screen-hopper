Profiles
Up to 4 profiles. Click a tab to edit, or pick the active profile below.
Bind a key to 0xfff30000 in any profile's mappings to cycle profiles; 0xfff30001..0xfff30004 activate slots 1..4 directly; 0xfff30010 toggles the jiggler (3 LED flashes = on, 5 = off).
